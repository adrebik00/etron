# CCI 반등 + 200일선 하단 + 피보나치 되돌림 전략

과매도(CCI ≤ -200)로 눌렸다가 되살아난 종목을 **200일선 아래**에서 사는 평균회귀 전략.
장기 추세가 무너진 종목(되돌림 0.618보다 깊음)과 이미 고점 근처라 먹을 폭이 없는 종목
(되돌림 0.20보다 얕음)을 양쪽에서 잘라내고, **200선까지 여유**가 있는 것만 남긴다.

```
strategy.py    공용 코어 — 데이터 로딩 / 지표 / 신호 판정 / 청산 플랜
backtest.py    로컬 CSV 차트 대상 백테스트
filter_lab.py  추가 진입 조건 후보의 효과를 전/후반 분할로 검증
monitor.py     오늘자 조건 충족 종목 탐색 + HTML 리포트
```

실행: `C:\Users\user\anaconda3\python.exe` (pandas / numpy / plotly / yfinance / FinanceDataReader)

## 전략 정의

### 진입 — 아래 전부 충족한 봉의 **종가**로 진입

| # | 조건 | 근거 |
|---|---|---|
| ① | 종가 < SMA200 | 하락 구간에서만 산다 |
| ② | CCI(20, hlc3)가 **-200 이하**로 눌린 뒤 **-100 위로 회복**, 회복이 **최근 5거래일** 내 | 급락 후 회복 타이밍 |
| ③ | 최대 10년 **고점(0.0)·저점(1.0)** 피보나치에서 종가가 **0.618 레벨 위** (되돌림 깊이 **0.20 ~ 0.618**) | 추세 붕괴 종목과 먹을 폭 없는 종목을 양쪽에서 제외 |
| ④ | **SMA200까지 여유 ≥ 8%** | 2차 목표가 200선이라, 거리가 없으면 애초에 먹을 게 없다 |
| ⑤ | **ATR(14) ≤ 종가의 4%** | 과도한 변동성 종목 제외 |
| ⑥ | **거래량 마름**: 5일 평균 거래량 ≤ 20일 평균 (`vol_dryup ≤ 1.0`) | 투매가 끝났다는 신호. 거래량 *급증*은 정반대로 성과를 해쳤다 |
| ⑦ | **피보 레벨까지 2% 이내** | 되돌림 레벨에서 실제로 지지받는 자리인지 확인 |
| ⑧ | **종가 > SMA5** | 최소한의 단기 반전 확인 |

②를 코드로 옮기면 `CROSS_UP[t]` = `CCI[t] ≥ -100` 및 `CCI[t-1] < -100` 및 직전 5봉 내
`CCI ≤ -200`, `SIGNAL_BAR[t]` = 최근 5거래일 내 `CROSS_UP` 존재.

③의 레벨은 **고점=0.0 / 저점=1.0** 기준이다.
`레벨가 = 고점 − 비율 × (고점−저점)` — 비율이 클수록 낮은 가격이고, 비율은 곧
**고점에서 얼마나 되돌렸는지(되돌림 깊이)**를 뜻한다. "0.618 위"는 0.618 레벨보다
비싼 구간, 즉 되돌림이 0.618보다 얕은 상태다.
10년 창은 봉 개수가 아니라 달력 기준(`rolling('3653D')`)이라 코인(365일 거래)과
주식(252일 거래)이 같은 10년을 본다. ④⑤는 `strategy.py`에서 개별 on/off 가능.

### 청산

| 단계 | 규칙 |
|---|---|
| 손절 | 최근 10봉 스윙 저점 −0.3%, 위험폭은 진입가의 **3~12%** 로 클램프 |
| 1차 익절 (50%) | 진입가 위 첫 피보나치 레벨, **1R~3R로 클램프** |
| 손절 상향 | 1차 체결 후 잔량 손절 → **본전** |
| 2차 익절 (잔량) | **SMA200 × 0.99**, 단 진입가 **+2% 하한** |
| 시간 청산 | 최대 **60거래일** |

봉 내부 순서는 보수적으로 손절 → 1차 → 2차. 갭이 나면 시가 체결
(하락 갭 손절 `min(손절가, 시가)`, 상승 갭 목표 `max(목표가, 시가)`). 편도 비용 0.1%.

> **2차 익절에 하한이 필요한 이유**: 진입가가 200선 바로 아래(−1~2%)인 경우가 많아
> `SMA200 × 0.99`가 진입가보다 낮아지면 진입 즉시 손실 청산된다. 이 하한을 빼고 돌렸을 때
> 포트폴리오 수익이 +88% → +18%로 무너졌다.

## 2. 추가 조건 실험 — `filter_lab.py`

```bash
C:\Users\user\anaconda3\python.exe filter_lab.py --group us_stock
```

`backtest.py`가 남긴 원장을 읽어 후보 조건 18개를 평가한다. 핵심은 "좋아 보이는 조건
찾기"가 아니라 **우연 걸러내기**라, 모든 조건을 전반기(~2016)/후반기(2017~)로 나눠
양쪽에서 같은 방향으로 작동할 때만 `OK`를 준다.

### 채택한 것

| 조건 | 통과율 | 기대값 | Δ전반 | Δ후반 |
|---|---|---|---|---|
| **SMA200까지 여유 ≥ 8%** | 50% | +0.129R | +0.043 | +0.051 |
| **ATR ≤ 종가의 4%** | 64% | +0.098R | +0.052 | +0.003 |
| (RSI 상승 다이버전스) | 13% | +0.129R | +0.091 | +0.028 |

기준선은 +0.078R. `여유 ≥ 8%` + `ATR ≤ 4%` 조합이 **+0.175R / PF 1.31**로 가장 안정적이다.

### 기각한 것 — 직관과 반대로 나온 것들

| 조건 | 기대값 | 판정 |
|---|---|---|
| 회복봉 거래량 ≥ 평균×2.0 | +0.027R | **기준선보다 나쁨.** 전반 +0.063 / 후반 −0.122로 방향도 뒤집힘 |
| 회복봉 거래량 ≥ 평균×1.5 | +0.032R | 위와 동일 패턴 |
| SMA5 > SMA10 | +0.042R | 승률은 68.4%로 최고인데 기대값 최하 |
| RSI(14) ≥ 40 | +0.063R | 승률 60.7%, 기대값 하락 |
| 20일 평균 거래대금 ≥ $10M | +0.065R | 유동성은 성과와 무관 |
| SMA5>SMA10>SMA20 정배열 | — | **19,658건 중 49건**. 급락 직후 진입이라 3중 정배열이 성립할 수 없다 |

**"회복을 확인하고 들어가면 좋아진다"는 가정이 데이터에서 부정됐다.** 거래량 급증,
RSI 회복, 단기 이평 반전 — 회복 확인 조건들은 하나같이 **승률은 올리지만 기대값은 떨어뜨린다.**
이미 반등한 뒤에 들어가니 200선까지 남은 거리가 줄어 먹을 폭이 사라지기 때문이다.
같은 이유로 되돌림 0.20 하한(고점 근처 제외)과 `여유 ≥ 8%`가 효과를 낸다. 이 전략의 우위는
**"회복이 확인된 종목"이 아니라 "목표까지 거리가 남은 종목"**에서 나온다.

시가총액은 과거 시점 값을 구할 수 없어(발행주식수 이력 필요) 20일 평균 거래대금으로
대신했다. 어떤 임계값에서도 효과가 없었다.

### 2차 실험 — 홀드아웃 검증

1차에서 채택한 ④⑤ 위에, 후보 20종을 더 얹어 **전반기(~2016)만 보고 조합을 고른 뒤
후반기(2017~)를 손대지 않고 확인**했다. 상위 조합 12개가 전부 후반기에서도 기준선을
넘겼다 — 커브피팅이 아니라는 뜻이다.

| 조합 | 전반기 (선택용) | 후반기 (홀드아웃) |
|---|---|---|
| **거래량마름 1.0 + 피보근접 2% + 종가>SMA5** | +0.370R / PF 1.57 | **+0.353R / PF 1.73** |
| 거래량마름 1.1 + 피보근접 3% + 종가>SMA5 | +0.342R / PF 1.56 | +0.280R / PF 1.63 |

전반기와 후반기가 거의 차이가 없어(0.370 → 0.353) 이 조합을 기본값으로 채택했다.

### 2차 실험에서 기각한 것

| 조건 | 기대값 | 판정 |
|---|---|---|
| **SPY > 자기 SMA200** | +0.080R | **전·후반 모두 악화(−0.034/−0.073).** 시장이 강할 때 오히려 나쁘다 |
| SPY 1년고점 대비 −5% 이내 | +0.064R | 전 후보 중 최악 |
| 볼린저 %B ≤ 0.2 | +0.079R | 더 눌린 걸 사는 게 낫지 않다 |
| CCI 최저 ≤ −300 | +0.119R | 눌림이 깊을수록 좋은 것도 아니다 |
| 52주 고점 −25% 이내 | +0.112R | 위치 자체는 무의미 |
| 직전 저점보다 높은 저점 | +0.139R | 통과 2%, 표본 부족 |

**시장 국면 필터가 역효과였던 게 가장 뜻밖이다.** 하락장에서 크게 깨지던 전략이라
"강세장에서만 사자"가 당연히 먹힐 줄 알았는데, 반대로 나왔다. 급락 구간이야말로
평균회귀 기회가 큰 자리이고, 하락장 손실은 *시장 국면*이 아니라 *투매 중 진입*이
문제였다. 그래서 시장을 보는 대신 **거래량 마름**(투매 종료 확인)이 효과를 냈다.

### RSI 다이버전스 — 1차에서는 유효했으나 최종 채택 안 함

④⑤만 있던 시점에는 기대값 +0.14R → +0.21R로 가장 강한 조건이었다. 그러나 ⑥⑦⑧을
채택한 뒤 다시 얹으니 **+0.33R → +0.27R로 오히려 나빠졌다**(162건). 다이버전스가 잡던
"저점이 다져지는 중"이라는 정보를 거래량 마름과 피보 지지가 이미 더 잘 잡고 있다.
`USE_RSI_DIV_FILTER = False` 로 두고, 참고용으로 리포트에 `다이버전스 ✓` 배지만 남겼다.

### 읽을 때 주의

- 2차 실험은 전반기에서만 조합을 고르고 후반기로 확인하는 홀드아웃을 썼지만, 1차에서
  채택한 ④⑤는 전 구간을 보고 골랐다. 그만큼은 여전히 낙관 쪽으로 치우친다.
- **연 48건(≈2주에 2건)으로 신호가 매우 드물다.** 일간 모니터링에서 며칠씩 0건이
  나오는 게 정상이다. 신호가 더 필요하면 `--relaxed`(거래량마름 1.1 / 피보근접 3%)를
  쓰면 되고, 이 경우 기대값 +0.33R → +0.26R, PF 1.63 → 1.56 으로 내려간다.
- 자산곡선은 **실현손익 기준**이라 보유 중 평가손익은 MDD에 안 잡힌다. 실제 MDD는 더 깊다.
- 코인은 필터 통과가 1건뿐이라 이 설정에서는 사실상 대상이 아니다.

0건인 날이 대부분이므로, **실질적인 일간 감시 목록은 관찰 쪽**이다.
실행 끝에 단계별 통과 종목 수(퍼널)가 찍혀 어느 조건이 병목인지 바로 보인다. 각 구간마다 요약 표(200선 여유 / ATR% / 거래량마름 / 피보근접 / 다이버전스 / CCI /
거래량 마름 / 피보 근접 / 회복일 / 되돌림 깊이 / 진입·손절·1차·2차 목표·위험폭)와
종목별 차트 카드가 붙는다.

### 차트 (종목당 3단)

| 단 | 내용 |
|---|---|
| 상 (50%) | 최근 320봉 캔들 + **SMA200**(주황) + 범위 내 **피보나치 레벨**(0.618은 굵은 주황) + CCI 회복 지점(▲) + 현재가(●) |
| 중 (20%) | **CCI(20)** + 0 / **−100** / **−200** 기준선 |
| 하 (30%) | **최근 10년 종가** + **피보나치 7개 레벨** + 고점(0.0)·저점(1.0) 앵커 |

상단 y축은 0.618 레벨이 가까우면 같이 보이도록 넓히되, 캔들이 납작해지지 않게 확장폭을
캔들 범위의 50%까지만 허용한다. 하단 10년 패널은 주봉 간격으로 솎아 용량을 줄인다.

### 실행 시 참고

- 장중에 돌리면 마지막 봉이 미완성 종가라 장 마감 후 결과와 달라진다.
- 미국 전 종목(~5,700개) × 10년 수신은 8분 안팎. 상장폐지·티커 불일치로 10%가량은 못 받는다.
- 표의 진입가에는 편도 슬리피지 0.1%가 반영돼 있다.

## 5. 피보나치 앵커 실험 — 10년 고저 vs 최근 스윙 파동

10년 최고/최저는 종목과 무관한 옛 지점이 잡히기 쉬우니, **ZigZag 로 최근 상승 파동
(의미있는 저점 → 그 뒤 최고가)** 을 앵커로 쓰면 어떨까? `strategy.swing_anchors()` 로
구현하고 `--fib-mode swing` 으로 비교했다.

미래를 보지 않도록 저점은 **pct 만큼 반등한 뒤에야 확정**하고, 고점은 그 저점 이후의
최고가를 쓴다. 데이터를 앞에서 잘라 다시 계산해도 과거 앵커가 변하지 않음을 확인했다.

### 결과 (청산 = 손절 + 30일, 미국주식)

| 설정 | 건수 | 승률 | 기대값 | PF | 전반/후반 |
|---|---|---|---|---|---|
| **10년 range · near 2.0%** | **910** | 48.4% | **+0.414R** | **1.84** | +0.456 / +0.394 |
| 10년 range · near 1.0% | 516 | 47.3% | +0.372R | 1.80 | +0.325 / +0.396 |
| 스윙 15% · near 2.0% | 634 | 45.7% | +0.357R | 1.61 | +0.478 / +0.285 |
| 스윙 15% · near 1.0% | 439 | 46.9% | +0.400R | 1.76 | +0.439 / +0.378 |
| 스윙 15% · near 0.6% (스케일 보정) | 302 | 46.4% | +0.402R | 1.84 | +0.422 / +0.391 |
| 스윙 20% · near 2.0% | 1,002 | 44.7% | +0.295R | 1.50 | +0.405 / +0.229 |
| 스윙 30% · near 2.0% | 1,219 | 45.0% | +0.297R | 1.56 | +0.283 / +0.305 |

### 결론 — 앵커를 바꾸는 것보다 '얼마나 좁게 거느냐'가 전부였다

처음엔 스윙 앵커가 크게 밀리는 것처럼 보였다(+0.36R vs +0.41R). 원인을 앵커 폭에서
찾았다.

| 앵커 | 폭(종가 대비) | 레벨 간격 |
|---|---|---|
| 10년 range | 112% | **~13.3%** |
| 스윙 15% | 33% | **~3.8%** |
| 스윙 20% | 43% | ~5.1% |

`⑦ 피보 레벨까지 2% 이내`의 선별력이 **레벨 간격에 좌우된다.** 10년 앵커는 레벨이
13% 간격이라 "2% 이내"가 드문 일치지만, 스윙 앵커는 4% 간격이라 거의 자동으로 통과한다.
같은 숫자가 전혀 다른 강도의 필터였던 것이다.

스케일을 맞춰(2% × 3.8/13.3 ≈ 0.6%) 다시 비교하니 **+0.402R / PF 1.84 로 10년 range와
사실상 동일**해졌다. 다만 트레이드가 302건으로 1/3이다.

- **스윙 앵커는 품질을 못 올린다.** 잘해야 같고, 표본만 3배 줄어든다.
- **피보 레벨 자체가 일하는 게 아니다.** 앵커를 어디에 걸든 정규화하면 결과가 같다는 건,
  ⑦이 "되돌림 지지"를 잡는 게 아니라 **가격 위치를 좁게 제한하는 장치**로 작동한다는 뜻이다.
- 그래서 기본값은 `FIB_MODE = 'range'` 로 되돌렸다. 스윙 모드는 `--fib-mode swing`
  으로 남겨뒀고, 쓸 경우 `--fib-near` 를 레벨 간격에 맞춰 좁혀야 한다.

## 데이터 위생 처리

수집 원본에 오류틱이 섞여 있어 그대로 돌리면 결과가 오염된다. 예: `ASTH.csv`는
2013-11-07 하루만 `5.4 → 100.1 → 5.4`로 튀는데, 이 봉의 고가가 SMA200 터치 청산에 걸려
**+2120%짜리 가짜 트레이드**를 만들었다. `strategy.clean_ohlcv()`가 세 가지를 처리한다.

1. 다음 봉에서 곧바로 되돌리는 **단발 스파이크 봉** 제거 (미국주식 82봉 / 61종목)
2. 되돌리지 않는 **5배 이상 레벨 점프**(티커 재사용·미조정 병합)는 이전 구간 절단 (39종목)
3. 시·종가 대비 말이 안 되는 **고가·저가 클램프**

전체 650만 봉 중 0.71%만 손대며, 이 처리 후 최대 트레이드가 +2120% → +42%로 정상화됐다.
